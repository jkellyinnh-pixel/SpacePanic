# Space Panic

This is a clone of the game of Space Panic, an arcade game I first encountered in 1982 as a teenager. 

The object of the game is to kill the aliens before your oxygen runs out. To do this, dig holes to trap the aliens, then fill the holes to make them fall to the level below. 

I've changed the game slightly from the original by eliminating the need to make higher-level aliens die by dropping them more than one level. They will all die when falling only one level. However, if you can cause the aliens to fall multiple levels, the points awarded are increased. 

Use the arrow keys to move, and the Z and X keys to dig/fill holes.
